# Operator

---

Enum of available query operators.

## Cases

- `Operator::EQUALS` for equals (equivalent to `=`)
- `Operator::NOT_EQUALS` for not equals (equivalent to `!=`)
- `Operator::CONTAINS` for contains (equivalent to `contains`)
- `Operator::NOT_CONTAINS` for not contains (equivalent to `!contains`)
- `Operator::HAS` for has (equivalent to `has`)
- `Operator::NOT_HAS` for not has (equivalent to `!has`)

> [!CAUTION]
> Using string values instead enum is deprecated and will be removed in the next major release.
